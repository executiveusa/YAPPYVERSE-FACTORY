# Living Story Card — Cadillac Evidence

Smallest judgeable implementation of the `living-html-story-cards` method.

## What this proves

- one approved still can become a layered 2.5D interactive scene without generated video;
- depth can be created with duplicated image planes, masks, scroll/pointer transforms, and restrained lighting/atmosphere;
- an evidence interaction can change player knowledge without changing canon;
- mobile can use vertical framing + scroll-controlled discovery rather than hover;
- reduced-motion users retain the full evidence interaction;
- no WebGL, video runtime, or external JavaScript library is required.

## Source asset

`assets/pauli/reference/pauli_reference_cadillac_v001.jpg`

The experiment does not repaint or regenerate the asset.

## Effects

Only two motivated liveness effects are enabled:

1. rain;
2. chrome/light glint.

The surveillance scan is treated as interface texture, not a third narrative effect.

## Interaction / payoff

The evidence hotspot opens a receipt explaining that the vehicle match changes **what the player knows**, not what happened. This is the minimal implementation of the Story Authority vs Player Authority boundary.

## Mobile acceptance

Primary target: `390x844`.

PASS when:

- the car remains legible;
- no horizontal page overflow appears;
- evidence hotspot remains reachable by touch;
- no hover is required;
- reduced-motion mode preserves the clue;
- scroll stays responsive;
- scene remains usable if all animations are removed.

## Gauntlet

Reference bars:

- locked Cadillac source image for fidelity;
- `oso95/scroll-world` for continuous-world behavior when this card is chained;
- the Where's Pauli `Perceptual Seam Lock` contract for reversible transitions.

Fresh critic must return `WIN` or `LOSE` and identify one biggest gap.

Do not promote this experiment into the product until that review happens.
